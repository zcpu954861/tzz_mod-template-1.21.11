# 7.9 WebAdmin 虚拟方块设备原生触发配置 P1 验收

## 范围

本轮只验收 `virtual_block_device` 原生触发配置的只读摘要、触发方式显示过滤、BlockState 当前方块属性读取基础，以及统一设备配置 modal 内的原生触发配置骨架。

P1 不验收写入，不应出现 native trigger 保存按钮或持久化写 API。

## 前置条件

1. 使用新世界或已完成 7.8 验收的测试世界。
2. WebAdmin 已登录 EDITOR / OWNER 或 VIEWER 账号。
3. 至少存在一个 `virtual_block_device`。
4. 建议准备一个绑定到带 BlockState 属性方块的 VBD，例如 lever / button / door。

## 浏览器验收步骤

Guard marker：
- 只显示选中触发摘要
- 红石摘要
- BlockState 属性读取
- 容器 open / close / change 摘要
- 不出现 itemSubmit / consume / ConditionEngine / 路径图
- Console / Network

1. 打开 `#/virtual-block-devices`。
2. 进入任意 VBD 详情页。
3. 确认详情页出现“原生触发配置”区域。
4. 确认触发方式选择器存在，并包含 6 类触发源：
   - 红石 / powered
   - BlockState
   - 右键交互
   - 容器打开
   - 容器关闭
   - 容器内容变化
5. 只选择“红石 / powered”，确认只显示红石摘要，不显示其它触发摘要。
6. 只选择“BlockState”，确认只显示 BlockState 摘要。
7. BlockState 摘要中确认：
   - 当前方块属性来自绑定方块实际属性。
   - 属性值下拉 / 预览只展示该属性实际支持值。
   - 不显示泛用属性大列表。
8. 只选择“右键交互”，确认显示：
   - interactionEnabled
   - interactChannel
   - interactionCooldownTicks
   - 最近交互玩家 / 结果
   - 7.8 interaction item matcher 作为条件层关联摘要。
9. 分别选择容器打开、容器关闭、容器内容变化，确认只显示对应摘要。
10. 打开“编辑设备配置”modal。
11. 确认 modal 内有“原生触发配置”section。
12. 确认该 section 明确是 P1 只读骨架，不提供保存 native trigger 的按钮。
13. 确认 7.8 “交互物品匹配”section 仍存在且可用。

## 禁止项检查

页面中不应出现：

- itemSubmit 编辑器。
- consume 编辑器。
- inventory / equipment / armor 编辑器。
- ConditionEngine。
- 成功 / 失败路径图。
- graph / mind-map / Scratch-like 编辑器。
- raw JSON textarea。
- 容器内容变化物品模板 GUI。
- native trigger POST / PATCH / DELETE 请求。

## Network / Console 检查

1. 打开 DevTools Network。
2. 切换触发方式 selector。
3. 确认不会发送 POST / PATCH / DELETE。
4. 允许出现 GET：
   - `/api/devices/<deviceId>`
   - `/api/webadmin/virtual-block-devices/<deviceId>/native-triggers`
5. Console 不应出现新的 JavaScript error。

## 布局检查

1. 大屏下原生触发摘要不应让左侧或右侧长短严重失衡。
2. 摘要卡应均衡分布，不应无意义横跨整行。
3. 中小屏下不应重叠、横向撑爆或遮挡按钮。
4. 统一设备配置 modal 内 section 应在内部滚动区域内显示，不应撑出 fixed modal。

## 失败判定

任一情况视为失败：

- VBD 详情页没有“原生触发配置”区域。
- selector 缺少六类原生触发源。
- 选择单一触发源后仍显示其它触发摘要。
- BlockState 属性不是来自当前绑定方块实际属性。
- 目标值不是来自该属性实际支持值。
- P1 出现 native trigger 保存按钮或写 API。
- 出现 itemSubmit / consume / ConditionEngine / 路径图 / raw JSON。
- 打开统一设备配置 modal 后找不到原生触发配置 section。
- 7.8 interaction item matcher 入口回退。
- Console 出现新错误。
