# 7.5 WebAdmin 前端重构第二阶段第一批页面验收

本轮只验收 Step 2 第一批 5 个主页面：

- 信号监听器：`#/listeners`，兼容 `#/signal-listeners`
- 动作列表：`#/actions`
- 信号设备：`#/devices`
- 虚拟方块设备：`#/virtual-block-devices`，兼容 `#/block-devices`
- 事件历史：`#/history`，兼容 `#/events`

不得验收为已完成：其它剩余主页面、子详情页新增、matcher、itemSubmit、Scratch-like editor、ConditionEngine。

## 数据准备命令

以下命令来自当前命令注册代码。执行时替换 `<pos>`、`<channel>`、`<listener>`、`<name>`、`<ticks>` 等参数，不要执行裸父命令。

## 通用验收

- 页面在 7.5 shell、sidebar、topbar 内显示，sidebar active 状态正确。
- 不出现旧 WebAdmin 页面样式回退。
- 图标使用当前 7.5 纯色几何图标体系，不使用 emoji、字母或旧无色图标。
- 所有没有完整后端支持的写操作保持 disabled，不发送 POST / PATCH / DELETE。
- Console 无 JS runtime error。
- Network 无未知新增后端 API。
- silent refresh 不触发 Document reload，不闪屏，不重置筛选、分页、滚动。

## 信号监听器页面

- `#/listeners` 能打开，`#/signal-listeners` 兼容。
- 顶部统计显示监听器总数、启用、停用、绑定频道、今日触发。
- 表格列包含监听器名称 / ID、频道、状态、冷却时间、动作数量、最后触发、操作。
- 频道长文本 ellipsis，状态 badge 清晰，冷却时间显示 tick。
- 无 listener 详情页时，整行不跳坏路由；频道按钮可进入已有频道详情。
- 添加监听器、批量导入、导出配置、编辑保持 disabled。
- silent refresh 约 10 秒，不重置筛选 / 分页 / 滚动。

## 动作列表页面

- `#/actions` 能打开，现有 `#/actions/<id>` 详情 route 不回退。
- 页面使用表格 + right rail。
- 顶部统计显示动作总数、可用动作、需关注、今日执行、失败次数。
- 表格列包含动作名称 / ID、类型、描述、状态、标签、最近执行、操作。
- right rail 显示动作类型分布、状态分布、快速筛选、动作类型说明。
- 已有详情 route 的行和查看按钮可进入动作详情。
- 添加动作、编辑、删除、批量操作、导入导出保持 disabled。
- 不出现动作编辑器、动作链编辑器或 Scratch-like editor。

## 信号设备页面

- `#/devices` 能打开，现有 `#/devices/<id>` 详情 route 不回退。
- 页面使用表格 + right rail。
- 顶部统计显示设备总数、启用、禁用、今日触发、最近触发设备、未绑定频道。
- 表格列包含设备名称 / ID、类型、频道、位置、状态、最近触发、Doctor、操作。
- 类型能区分 `signal_emitter`、`signal_receiver`、`action_relay`、`virtual_block_device`。
- device id、channel、坐标长文本不穿列。
- 行和查看按钮可进入已有设备详情。
- 添加设备、批量启用、批量禁用、测试设备、清空统计、导入导出保持 disabled。

## 虚拟方块设备页面

- `#/virtual-block-devices` 能打开，`#/block-devices` 兼容。
- 页面使用表格 + right rail。
- 数据来自 `/api/devices` 过滤 `virtual_block_device`，可见行用已有 `/api/devices/<id>` 详情缓存补齐配置摘要。
- 表格列包含设备名称 / ID、绑定方块、位置、触发类型、通道、状态、条件配置、最近触发、操作。
- Minecraft 原版方块 / 物品不使用 WebAdmin 图标伪造；当前无材质资源时只显示文本或 `--`。
- 行和查看按钮可进入已有设备详情。
- 添加虚拟设备、编辑条件、绑定 / 解绑、测试触发、导入导出保持 disabled。
- 不实现 matcher、itemSubmit、复杂条件编辑器或新增编辑 API。

## 事件历史页面

- `#/history` 能打开，`#/events` 兼容。
- 数据来自 `/api/signals/history?limit=500`。
- 表格列包含时间、频道、来源类型、来源对象、动作数、结果、操作。
- 频道长文本 ellipsis，来源对象最多两行，结果 badge 清晰。
- 无 history 详情页时，整行不跳坏路由；行内已有频道 / 设备 / 区域 / 动作跳转按当前数据可用。
- Live、导出当前结果、清空历史保持 disabled。
- silent refresh 约 10 秒，不整页 reload。

## 响应式验收

分别检查：

- 3840x2160 / 2560x1440：页面自然扩展，不缩成小画布。
- 1920x1080：表格与 right rail 稳定。
- 1536x864：接近参考稿密度。
- 1366x768：筛选栏可换行，按钮不压文字。
- 1280x720：right rail 下移或保持可读，不越界。
- 1024x768：表格容器横向滚动，分页不压最后一行。

## 保持 Step 1 不回退

- Dashboard 整卡点击、hover、键盘 Enter / Space 正常。
- SignalBridge 整行点击和详情按钮正常，channel encode / decode 正常。
- Receivers pulseTicks 默认 5 tick、改为 20 tick 后 silent refresh 更新仍正常。
- Receivers visible detail cache 与 silent refresh 不回退。
- 登录页和 app shell 仍为 7.5 样式。
