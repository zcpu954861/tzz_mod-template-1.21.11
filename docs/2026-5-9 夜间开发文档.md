2. Windows 本地 vs Linux 云端差异
============================================================

用户本地是 Windows，平时命令可能是：

.\\gradlew.bat clean build
.\\gradlew.bat stabilizationGuardTest --rerun-tasks

但你在 Codex Cloud / Linux 环境中必须使用 Linux 命令。

优先使用：

./gradlew clean build
./gradlew stabilizationGuardTest --rerun-tasks

如果 ./gradlew 没有执行权限，先运行：

chmod +x ./gradlew

然后再运行：

./gradlew clean build
./gradlew stabilizationGuardTest --rerun-tasks

不要在 Linux 云端使用 Windows 绝对路径，例如：

E:\\minecraftserver\\fabricmod\\...

不要在代码或文档中写死 Windows 路径。  
文档中如需说明本地路径，使用相对路径。

路径规则：

- Linux 使用 `/`
- Java resource path / web path 使用 `/`
- 不要混用 `\\`
- 不要创建大小写仅不同的文件，例如 `AGENTS.md` 和 `agents.md`
- Linux 文件系统大小写敏感，Windows 不敏感；避免大小写冲突

换行规则：

- 不要大规模重写 CRLF/LF
- 不要只因为行尾不同改全文件
- `git diff --check` 必须通过
- CRLF warning 可记录，但不要引入实际 whitespace error

Shell 规则：

- 默认使用 bash/sh 语法
- 不要使用 PowerShell 专用语法
- 不要使用 `dir`、`copy`、`del` 等 Windows 命令
- 使用 `ls`、`cp`、`rm`、`find`、`grep`、`rg`
- 删除文件前必须确认，不要删除 logs/

Node 规则：

- 如果需要检查生成的前端 JS，优先使用可用 `node`
- 如果 PATH 上没有 node，寻找环境中 bundled Node
- 如果 Node 不可用，报告原因，但不能跳过 Java build / guard

WebAdmin 运行规则：

- WebAdmin 是 Minecraft / Mod 内置服务
- Codex Cloud 通常无法真实访问用户本地 `http://127.0.0.1:18080/`
- 不要把无法访问 18080 视为失败
- 真实浏览器验收由用户回到本地后执行
- 你仍然必须做 build、guard、JS check、smoke test、route/render/realtime 代码级验证
